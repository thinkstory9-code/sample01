# 마음이 흐린 날에 — 사진과 짧은 글을 담은 위로의 책자

기존의 책자형 홈페이지에 **다섯 장의 사진 이미지, 짧은 위로의 글, 새로 만든 배경 음악**을 넣어 완성한 버전입니다. 압축을 풀고 `index.html`을 열면 바로 볼 수 있으며, GitHub Pages에도 올릴 수 있습니다.

## 포함된 페이지

1. **표지 — 마음이 흐린 날에** : 산 위로 떠오르는 아침 해
2. **괜찮지 않은 날도 있어요** : 비 오는 창가
3. **잠시 멈춰도 괜찮아요** : 따뜻한 차
4. **오늘은 한 걸음만** : 햇빛이 드는 숲길
5. **조금은 가벼운 내일이기를** : 햇빛이 닿는 들판

## 미리 보기

`index.html`을 더블클릭해 브라우저에서 엽니다. **이전/다음** 버튼, 키보드 좌우 화살표, 휴대폰 좌우 스와이프로 페이지를 넘길 수 있습니다.

## 새로 만든 배경 음악 — 숨 고르기

- **제목:** 숨 고르기 (Room to Breathe)
- **길이:** 약 1분 25초, 반복 재생
- **분위기:** 잔잔한 피아노와 은은한 신시사이저 화음
- **제작:** 이 책자를 위해 새로 작곡한 멜로디·코드 진행을 수학적 파형으로 직접 합성했습니다. 기존 노래, 기존 녹음, 음악 샘플, 사운드폰트를 사용하지 않았습니다.

홈페이지 오른쪽 위 **음악 켜기**를 클릭하면 재생되고, **음악 끄기**를 클릭하면 일시정지됩니다. 옆의 슬라이더로 음량을 조절할 수 있습니다. 한 번 재생하면 페이지를 넘겨도 음악은 계속되며 끝나면 다시 시작됩니다.

**브라우저 자동 재생 제한**과 방문자 선택을 존중하여 첫 방문 시에는 음악이 꺼져 있습니다. 방문자가 재생 버튼을 눌러야 시작됩니다.

음악 파일은 `music/room-to-breathe.mp3`이며 인터넷 없이도 재생됩니다. 원하는 음원으로 바꾸려면 같은 경로와 파일 이름에 MP3를 넣거나 `index.html` 안 `<audio>`의 `src` 경로를 수정하면 됩니다.

`music/compose_original.py`는 이 음악의 **원본 작곡·합성 소스 코드**입니다. 음악을 재생하는 데는 이 파일이나 Python이 필요하지 않습니다. 기존 음원이나 샘플을 쓰지 않고 새로 만든 작품이지만, 세상 모든 기존 곡과 우연한 유사성이 절대 없다고 보증할 수는 없습니다.

## 글 수정하기

`content.js` 파일을 텍스트 편집기로 열어 아래 항목을 바꿉니다.

- `siteName`: 홈페이지 이름
- `title`: 페이지 제목. `\n`으로 줄바꿈
- `body`: 본문. `\n`으로 줄바꿈, `\n\n`으로 문단 구분
- `caption`: 사진 아래 문구
- `label`: 페이지 상단의 작은 표기

예시:

```js
title: "천천히 가도\n괜찮아요",
body: "오늘은 조금 쉬어가도 좋아요.\n\n작은 발걸음도 발걸음이에요.",
```

## 사진 바꾸기

`photos` 폴더에 직접 찍은 JPG, PNG 또는 WebP 사진을 넣고 `content.js`에 지정하세요.

```js
image: "photos/my-photo.jpg",
imageAlt: "사진에 대한 간단한 설명",
```

사진은 중앙을 기준으로 알맞게 잘려 표시됩니다. 현재 포함된 다섯 장은 **AI로 생성한 사진풍 이미지의 사진 영역을 추출한 것**이며, 웹사이트 사용을 위해 WebP로 최적화했습니다. 사진 파일을 삭제하지 않으면 인터넷 연결 없이도 보입니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 압축 파일을 풀고 그 안의 `index.html`, `content.js`, `photos` 폴더, `music` 폴더를 저장소 **최상위**에 업로드합니다. (`mini_booklet_homepage` 폴더째 올리지 마세요.)
3. 저장소의 **Settings → Pages**에서 **Deploy from a branch → main → /(root)**를 선택합니다.
4. 공개된 `https://계정명.github.io/저장소명/` 주소를 엽니다.

## 특징

- PC 화면에서는 책을 펼친 모양, 모바일에서는 위아래 페이지 구성
- 사진·글·오리지널 음악이 있는 정적 사이트 — 회원가입, 외부 플러그인 없음
- 모든 사진·음악 파일을 로컬 포함, GitHub Pages에서 별도 서버 불필요
- 사진과 문구는 `content.js`에서 언제든 교체 가능
